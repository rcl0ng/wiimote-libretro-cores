# VICE x64 Analog Gun (C64)

Included in Wiimote Libretro Custom Cores v1.2.0.

**Binary:** `cores/vice_x64_analog_gun_libretro.dll`  
**Core info:** `info/vice_x64_analog_gun_libretro.info`

Commodore 64 analog/lightgun pointer development build; game-specific input and peripheral selection require testing.

## Setup

Back up current configs, install the DLL and `.info` to the configured RetroArch directories, and ensure Lichtknarre/vJoy inputs map to separate devices where appropriate. Choose the custom core explicitly; stock cores remain available. See `docs/INPUT-SETUP.md` and `retrobat/INSTALL.md`.
