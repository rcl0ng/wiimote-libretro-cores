# Publishing and maintaining v1.2.0

Tag: `v1.2.0`. See the [release page](https://github.com/rcl0ng/wiimote-libretro-cores/releases/tag/v1.2.0).

Assets: `Custom_Cores_v1.2.0.zip`, `Wiimote_Libretro_v1.2.0_Windows_x64.zip`, and `Wiimote_Libretro_v1.2.0_Source.zip`. Unlike the automatically generated repository source archives, the separate Source ZIP holds historical sources and supplemental development materials.

For repository-only documentation updates after publication, commit changes to `main` without moving the already published v1.2.0 tag. If the release asset contents are changed, disclose the changed files and checksums and consider a maintenance version rather than silently replacing existing artifacts.

Before committing, review `.info` names, license notices, documentation/core counts, and the RetroBat optional references. Do not overwrite locally installed RetroBat configs with these example files.
